# 🚀 Launch Press

**Launch Press** is a lightweight WordPress developer utility plugin that automates the common setup tasks required after installing a fresh WordPress site.

Instead of repeating the same manual configuration on every project, Launch Press lets you handle everything from one centralized dashboard — helping developers launch projects faster, cleaner, and more consistently.

---

# ✨ Features

* One-click initial WordPress setup
* Bulk default configuration handling
* Developer-focused workflow
* Reusable across multiple projects
* Lightweight & modular architecture
* Clean admin interface
* Time-saving setup automation
* WordPress standards friendly

---

# 🎯 Purpose

Every new WordPress project usually requires repeating the same tasks:

* Configure settings
* Clean defaults
* Create pages
* Install essentials
* Adjust admin behavior
* Optimize development workflow

Launch Press centralizes these repetitive tasks into a reusable plugin so you can initialize projects in minutes instead of hours.

# 🛠 Installation

1. Upload the plugin to:

```text
/wp-content/plugins/launch-press
```

2. Activate the plugin from:

```text
WordPress Admin → Plugins
```

3. Open:

```text
Launch Press → Dashboard
```

4. Run the required setup modules.
